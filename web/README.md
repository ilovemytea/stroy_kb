# dusovstroimir

Публичная версия базы знаний «СтройМир» для телефона и компьютера.

Основной проект: https://github.com/ilovemytea/stroy_kb

## Сборка

Из основного проекта:

```powershell
py web/build_public.py
node web/tests/parity.mjs
py -m http.server 5173 --directory web/dist
```

При отдельном размещении исходников публичного сайта:

```powershell
py build_public.py --source W:/project/stroy_kb
node tests/parity.mjs
py -m http.server 5173 --directory dist
```

Затем откройте http://localhost:5173. Каталог `dist/` содержит готовый сайт и подходит для статического HTTPS-хостинга, в том числе для Sites и GitHub Pages. Обычные адреса статей и понятий имеют готовые HTML-файлы для поисковых роботов. Старые ссылки с `#/` также поддерживаются.

## Данные и алгоритмы

`build_public.py` берёт статьи, понятия, синонимы и правила из `data/knowledge.py`, каталог — из `data/catalog.sql`. Инвертированный индекс строится исходной поисковой машиной Python и экспортируется в JSON. В браузере работают BM25F, распознавание понятий, русская нормализация, исправление опечаток и продукционный вывод MYCIN.

Проверка сравнивает браузерную реализацию с исходным Python: словоформы всего словаря, 30 поисковых запросов с порядком выдачи и быстрыми ответами, 150 воспроизводимых сценариев экспертного вывода. Дополнительно проверяются экранирование HTML, фильтры и подсказки.

Публичная версия поддерживает чтение, поиск, граф онтологии, каталог и экспертный подбор. Автор редактирует знания в основном проекте и повторно выполняет сборку. Журнал поиска и счётчики просмотров публичной версии хранятся на устройстве посетителя. Серверная версия Flask/SQL Server и её редактор остаются в основном проекте.

После первого полного посещения service worker кеширует весь сайт для повторного открытия без сети. Смена данных или файлов интерфейса обновляет версию кеша. Для офлайн-режима нужен HTTPS либо localhost и браузер с поддержкой service worker.

SEO-проверка: `py web/tests/test_seo.py` из корня проекта. Отправка опубликованных URL в IndexNow: `py web/submit_indexnow.py`. Основной адрес: https://ilovemytea.github.io/stroy_kb/ .

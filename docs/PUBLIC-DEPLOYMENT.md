- Основной адрес: http://dusovstroimir.mooo.com/
- Карта сайта: http://dusovstroimir.mooo.com/sitemap.xml

- Исходный код: https://github.com/ilovemytea/stroy_kb

Публичному посетителю достаточно современного браузера телефона или компьютера. SQL Server, Python, вход в GitHub и вход в ChatGPT для просмотра сайта не нужны.

## Что реализовано в публичной версии

Все 37 статей, 95 понятий, 191 связь, 84 правила и 15 записей каталога экспортируются из основного проекта. В браузере работают интеллектуальный поиск BM25F, русский стемминг, синонимы, исправление опечаток, быстрые ответы со ссылками на статьи, граф онтологии и экспертный вывод MYCIN с объяснениями. Измерение скорости выполняется на устройстве посетителя; журнал запросов хранится только в его браузере.

Серверная версия Flask/SQL Server с редактором остаётся частью курсового проекта. Изменения для общего доступа автор вносит в исходную базу и публикует новой сборкой. Публичный сайт показывает знания из опубликованной сборки и не предоставляет посетителям изменение общей базы.

## Короткий сценарий демонстрации

1. Откройте главную страницу и покажите объём базы знаний.
2. Введите «минвата»: система распознает понятие «Минеральная вата».
3. Введите «гипсакартон»: покажите исправление опечатки.
4. Спросите «из чего делают силикатный кирпич»: откройте быстрый ответ и статью-источник.
5. В подборе выберите «Утепление», «Баня», «Фасад», «Эконом». Покажите рекомендацию минеральной ваты, отклонение пенополистирола и шаги вывода.
6. На странице онтологии отфильтруйте отношения «изготавливается из» и откройте понятие.
7. На странице исследования запустите измерение поиска.

Все эти примеры также открываются ссылками из раздела «О проекте» на самом сайте.

## Резерв перед защитой

Заранее откройте сайт на телефоне и ноутбуке с интернетом, дождитесь полной загрузки и выполните поиск. В браузерах с поддержкой service worker после первой полной загрузки кешируется весь сайт и база знаний. Повторное открытие и поиск могут работать без сети; очистка данных браузера удалит этот кеш. Для защиты сохраните прямую ссылку на сайт; появление в поисковой выдаче до даты защиты не гарантируется.

## Сборка и проверка

Из корня репозитория:

```powershell
py web/build_public.py
node web/tests/parity.mjs
py -m http.server 5173 --directory web/dist
```

Откройте http://localhost:5173. Для сборки нужен Python, для проверки эквивалентности алгоритмов — Node.js. Дополнительные зависимости Flask и ODBC для этой сборки не требуются.

Тест сравнивает браузерную реализацию с исходным Python: 2018 словоформ, 30 запросов с порядком выдачи и быстрыми ответами, 150 сценариев экспертного вывода. Дополнительно проверяются HTML-экранирование, фильтры, подсказки и ограничения выдачи.

## Обновление публикации

После изменения знаний или файлов в `web/` отправьте изменения в ветку `main`. Workflow «Publish dusovstroimir» соберёт данные, выполнит сравнение алгоритмов и обновит резервный сайт GitHub Pages. Основной сайт в Sites обновляется отдельно через публикацию соответствующего проекта dusovstroimir. Редактируемые исходники находятся в `web/src/`, готовые файлы — в `web/dist/`.

GitHub Pages предоставляет бесплатный адрес github.io для открытых репозиториев: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages


## Поисковая индексация

Сайт публикует 141 HTML-страницу, из них 139 включены в sitemap.xml. У всех статей и понятий есть обычные адреса, содержимое в исходном HTML, уникальные заголовки, описания и canonical. Поисковые результаты и журнал устройства помечены noindex. Старые ссылки с #/ продолжают открываться.

Проверки:

```powershell
py web/tests/test_seo.py
```

После успешной публикации можно отправить карту сайта в поисковые системы, поддерживающие IndexNow:

```powershell
py web/submit_indexnow.py
```

Скрипт предварительно проверяет опубликованный файл подтверждения, затем отправляет 139 URL. HTTP 200/202 означает приём уведомления, а не гарантированную индексацию. Проверочный файл по протоколу публикуется открыто и не является паролем аккаунта. Не отправляйте одни и те же страницы многократно без изменений.

Для Google можно добавить ресурс с префиксом http://dusovstroimir.mooo.com/ в Google Search Console, подтвердить его HTML-файлом или метатегом и отправить sitemap.xml. Нужна авторизация владельца в Google. Для проверки появления сайта используйте запрос dusovstroimir или site:dusovstroimir.mooo.com.

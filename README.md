# СтройМир — база знаний по строительным материалам

Курсовой проект «Проектирование базы знаний по строительным материалам», автор Дусов А.Э.

Это веб-приложение с интеллектуальным поиском. Запрос может быть словом, словосочетанием или предложением до 15 слов. Также в приложении есть онтология, экспертная система подбора материалов и редактор знаний.

## Открыть публичный сайт

[ctroimir — сайт для телефона и компьютера](http://dusovstroimir.mooo.com/)

Поиск, статьи, онтология, экспертный подбор и каталог доступны без установки и авторизации. Браузерная версия использует знания из этого репозитория. Повторное открытие без сети поддерживается на резервном HTTPS-адресе после первой полной загрузки; на HTTP-адресе mooo.com для работы нужна сеть. Исходники и сборщик находятся в `web/`.

Карта сайта для поисковиков: http://dusovstroimir.mooo.com/sitemap.xml

Статьи и определения публикуются отдельными HTML-страницами и доступны роботам без выполнения JavaScript. Добавлены канонические ссылки и метаданные. Появление в поисковой выдаче зависит от индексации поисковиками.

[Инструкция для защиты и обновления сайта](docs/PUBLIC-DEPLOYMENT.md).

## Состав

| Путь | Назначение |
|---|---|
| `sql/01_schema.sql` | Создание БД `StroyMir_KB`: каталог (`dbo`, из ЛР №5–11) и база знаний (`kb`, по ER-модели КП) |
| `sql/02_data.sql` | Наполнение. Генерируется `seed.py` из `data/knowledge.py` и `data/catalog.sql` |
| `sql/03_procedures.sql` | Представления, функции (в т.ч. рекурсивные), процедуры, триггеры |
| `data/knowledge.py` | Знания: понятия, синонимы, связи, статьи, вопросы и правила |
| `search/` | Поисковая машина: стеммер, исправление опечаток, BM25F, онтология |
| `expert.py` | Машина вывода: прямая цепочка, коэффициенты уверенности MYCIN |
| `app.py`, `templates/`, `static/` | Веб-интерфейс на Flask |
| `tests/` | Автотесты (pytest) |

## Запуск

**В PyCharm:** откройте `app.py` и нажмите Run. При прямом локальном запуске пароль редактора и случайный ключ сессий автоматически создаются в приватном файле `.env.local.json` рядом с `app.py` и используются при следующих перезапусках. Файл исключён из Git. Пароль для входа в редактор находится в поле `STROYMIR_ADMIN_PASSWORD` этого файла; не публикуйте его содержимое. Заданные переменные окружения имеют приоритет. Сервер слушает только `127.0.0.1:5000`.

SQL Server должен быть запущен. Настройки ниже также подходят для ручного запуска с собственными переменными окружения. При импорте приложения через WSGI автоматическое создание локального файла не выполняется: пароль и ключ нужно явно передать через окружение.


1. Запустите SQL Server (служба `MSSQLSERVER`).
2. Установите зависимости:
   ```
   py -m pip install -r requirements.txt
   ```
3. Создайте и наполните базу данных:
   ```
   py seed.py --deploy
   ```
   Скрипты `sql/01_schema.sql` → `sql/03_procedures.sql` → `sql/02_data.sql` можно также выполнить в SSMS.
4. В PowerShell задайте пароль редактора и случайный ключ подписи сессий:
   ```powershell
   $env:STROYMIR_ADMIN_PASSWORD = Read-Host "Задайте пароль редактора"
   $env:STROYMIR_SECRET_KEY = py -c "import secrets; print(secrets.token_hex(32))"
   ```
   Сохраните значения в защищённых настройках среды запуска и используйте тот же ключ при перезапуске приложения. Не добавляйте их в Git.
5. Запустите сайт в том же окне PowerShell:
   ```
   py app.py
   ```
   Сайт откроется по адресу http://localhost:5000. Для входа в редактор используйте заданный вами пароль. При WSGI-запуске обе переменные обязательны; прямой запуск `app.py` использует сохранённые локальные настройки.

Настройки подключения задаются переменными окружения: `STROYMIR_SQL_SERVER` (по умолчанию `.`), `STROYMIR_SQL_USER`, `STROYMIR_SQL_PASSWORD`, `STROYMIR_ADMIN_PASSWORD`, `STROYMIR_SECRET_KEY`.

## Тесты

```
py -m pytest tests
```

Тесты поиска и экспертной системы проходят без БД. Тесты веб-интерфейса пропускаются, если SQL Server недоступен.

Готовые пояснительная записка и презентация в `docs/` отражают исходную версию проекта. Актуальные настройки безопасного запуска приведены выше.

## Практические материалы и медиа

База содержит 55 статей, 106 понятий и 202 семантические связи. К статьям добавлены краткие выводы, шесть схем, пять фотографий с указанием авторов и девять обучающих роликов производителей. В публичной версии работают разделы «Практика», «Видео» и «Мои материалы»: избранное, история чтения и отметки в проверках сохраняются только в браузере текущего устройства. Видео загружаются после нажатия кнопки; доступность воспроизведения зависит от внешней площадки.

Для обновления действующей SQL-базы без пересоздания таблиц выполните `py sync_knowledge.py`, затем перезапустите `app.py`. Существующие статьи, их идентификаторы, тексты и просмотры сохраняются. `seed.py --deploy` предназначен для первоначального развёртывания и пересоздаёт таблицы. Источники фотографий и видео: `data/media_catalog.json`.
